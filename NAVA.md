# Nava Messenger (نوا)

Nava is a lightweight, low-data messenger for Afghanistan, built on the
[FluffyChat](https://github.com/krille-chan/fluffychat) client (AGPL-3.0) and
the open [Matrix](https://matrix.org) protocol.

Credits: this project is a soft fork of FluffyChat by Christian Pauly and
contributors. All upstream code remains AGPL-3.0-or-later; FluffyChat
trademarks and logo are not used here and have been replaced.
